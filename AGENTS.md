## Project Summary
Lotion AI is an all-in-one workspace powered by AI agents, inspired by Notion AI. It provides a clean, minimal interface for writing, planning, organizing, and automating work.

## Tech Stack
- Framework: Next.js 15 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS 4
- Icons: Lucide React
- Animations: Framer Motion
- UI Components: Custom components with a Notion-inspired design system

## Architecture
- `src/app/`: Next.js App Router pages and global styles
- `src/components/`: Reusable UI components (Navbar, Footer, Hero, AIFeatures, Projects, etc.)
- `public/`: Static assets

## User Preferences
- Theme: Light mode by default (soft off-white/light gray background)
- Color Palette: Muted blue primary accent, subtle green/orange highlights
- Typography: Geist Sans (clean sans-serif)
- Design: Minimalist, enterprise-ready, rounded corners (12px), subtle shadows

## Project Guidelines
- Follow the "Lotion AI" visual style: clean, calm, productivity-focused.
- Use `framer-motion` for subtle animations and micro-interactions.
- Maintain a clear hierarchy and generous white space.
- Ensure all sections are responsive.

## Common Patterns
- Section-based vertical flow
- Horizontal and grid cards for feature displays
- Floating labels and AI badges for visual interest
- Interactive project views (Kanban, Table, Gantt)
